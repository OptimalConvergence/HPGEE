## Freeze the scientific unit and source

Specify collection/version, geometry, half-open UTC interval, bands/order, native support, grid/scale, processing level, masks, auxiliaries and acceptance gates. Bind each sample’s audited support to the contract minimum; a pilot’s observed count is not a cohort-wide requirement. Make label eligibility target-specific; an unrelated missing co-measurement must not exclude a valid target. Check native method definitions and class support before replacing a source. Preserve measurement units, uncertainty and field/expert/lidar versus proxy/model-product provenance. Publication dates are not acquisition dates; unknown coordinates or clocks remain unresolved.

Count independent fields/sites/events separately from frames, visits and pixels. Distinguish native archive completeness, source enumeration, saved-pixel pairing, accepted temporal cycles and benchmark eligibility. Closing all dates in selected sites proves that cohort, not a publisher-wide source ceiling. Preserve the full publisher roster and source-specific exclusions when expanding scope.

## Diagnose the limiting stage

Measure planning/ranking, authentication/metadata, remote computation, payload writes, checkpoints and QA separately. Report useful new frames/bytes and full elapsed time; cache hits are not transferred bytes. Logical process write counters are not physical NFS IOPS, and bytes/time are not EECU. Optimize repeated ranking or full-state rewrites only after profiling, proving identical selections/replay and preserving healthy frozen workers.

On the user's shared cluster, use `slurm-workflow` for substantial work; sampling normally needs CPU-only allocations. Check the actual interpreter, imports, allocation and paths. Freeze transitive inputs and exercise real staging, production and audit entrypoints with exact argv. Use source-valid fixtures that preserve transport interfaces and distinct acquisition/observation clocks; simplified function mocks can bypass required guards. Exercise a successful OAuth response through the real SDK after budget accounting: downstream transports must use cached response.content when raw was consumed, rather than reading EOF again. A first-request interception alone misses this interface failure. Release guards need actual saved observer/controller/registry fixtures with producer and capture-code identities bound separately. An owned network producer's terminal proof releases its slot; unavailable recorder-own evidence stays UNKNOWN separately. A copied literal path does not fix variable-constructed paths, and PYTHONPATH alone does not isolate imports. Exercise first-send in a fresh CLI process with production import order: pytest module caches can hide same-name entrypoint imports. Missing receipts are acquisition facts; a read-only cold audit must not mutate producer claims or turn missing delivery into pixel-integrity failure.

## Tune bounded comparable work

For frozen HLS30/S1 original-scene series, read [raw-series transfer and cumulative telemetry](sampling/raw-series.md). It documents the shared `hpgee.transfer` callback, source-valid QA and cross-size reuse limits; throughput settings remain workload-specific.

Use small disjoint cohorts stratified by relevant geography/time/complexity, reverse or randomize trial order and retain valid outputs. Keep the scientific contract constant. Initialize one active EE transport per process with a blocking HTTP pool sized for the largest worker trial. Authentication background managers can deepcopy that transport; a per-host pool does not bound aggregate requests. Test the installed auth lifecycle, share copied transport identity and serialize durable reserve/read/settle operations; drain requests before final counters and replay every raw event, retaining conservative charges when historical IDs collide. Choose the smallest stable configuration near the measured optimum, including retries, memory and end-to-end QA. Historical worker counts are not defaults. See [metadata trials](sampling/metadata-tuning.md) only for that workload.

When route testing is requested or needed for a demonstrably failing/slow transfer, use `with-mihomo` to compare actual authentication, metadata and computePixels operations; they may need different routes. Freeze the standalone node configuration, not just its display name. Verify send-level proxy selection through the installed auth transport and actual requests adapter: inherited session proxies can defeat direct OAuth, while trust_env=False sessions ignore proxy environment variables and require explicit session.proxies for OAuth, metadata and payload. Bound a route probe with a process deadline as well as socket timeouts, because DNS and SDK retries can exceed a single-request timeout; preserve unknown costs after termination. A compute node has its own loopback; keep an owned proxy alive around the worker. Saved comparable responses prove scoped feasibility, not sustained throughput. Preserve useful routes, TLS checks and Codex's live proxy.

## Reuse safely and recover narrowly

Keep hot SQLite queues/catalogues on allocated local storage or in memory with sequential durable journals/checkpoints. Configure every geospatial runtime's local resources before imports, including independent pyproj/rasterio/pyogrio PROJ databases. Test replay and bind state to source/configuration identity; no shared Redis/cache service is assumed. Follow the maintained cluster storage policy rather than duplicate its machine inventory. The historical 37009 incident involved a candidate queue, not an enabled S2catalog; this does not make other hot SQLite databases suitable for NFS.

Prefer indexed spatial-first metadata queries and complete page enumeration with atomic scene/cursor commits. Distinguish a fully enumerated empty interval from a failed/truncated query. Validate canonical scene identity from the frozen collection and system:index: Image.id() may return only the exact basename. Batch related projection metadata into one request; validate the CRS, six affine coefficients and permitted type tags rather than compare whole response objects. Projection.transform() returns WKT. Exercise installed client request construction, including generated endpoint/query parameters, and saved real responses in parser/serialization fixtures; normalize only lossless representations while preserving source/time/geometry checks. Preserve local guard failures even when saved responses support a separate offline reconciliation.

Retry idempotent transport failures with bounded backoff; separate permission, parser/packaging, identity/integrity and scientific outcomes. Persist sanitized HTTP status, API reason and exception causes before classification; translated EEException messages can lose HTTP500/429 numbers, so inspect structured status in the cause/context chain rather than only message text. Use lowercase workload tags: the compute endpoint can reject uppercase values accepted by an SDK validator. Preserve good cached scenes/annotations and target only failed frames or required replacement candidates. When the original complete response contains only already-excluded scenes, repeat exports add no evidence. A bounded candidate cap or cloud failure is not source exhaustion: retain enumeration completeness/lower bounds, tried IDs and a deferred-search outcome. Extend budgets through a new source-bound contract and reuse hash-verified attempted artifacts; do not silently relabel historical capped exclusions as complete science.

Require real finite valid support in every required band and a nonempty common valid domain before accepting pixel delivery: an all() reduction over an empty mask proves nothing. Keep this integrity check separate from the original scientific coverage thresholds; retain source-empty holds and continue the bounded cohort. Check saved pixels over both the whole image and the entire native annotation support. Project image validity onto the full native grid, or extend the image grid over vector support; outside-footprint support stays invalid in the denominator. Reparse materialized native records against publisher rows or frozen content: agreeing label/receipt hashes alone do not verify measurement values. Keep categorical resampling, temporal completeness and auxiliary recipes source-specific. Preserve native auxiliary grids and interval clocks; ending-hour accumulations, missing/gapfilled observations and target-derived fields need explicit treatment. Feasible coarse/hourly inputs do not establish fine-resolution truth or predictive skill. An annotation pause can use an authorized S2-only queue, but imagery-only receipts cannot become paired or benchmark-ready until native labels and support are independently audited.

## Close the exact contract and hand off

After producer termination, reconcile the authoritative journal, accepted index, final receipts, independent pixel proofs and actual terminal evidence. Separate attempted unresolved failures from untouched reserves. Audit source identities and all required phases before accepting groups; count shared physical sources once. Successful scheduler exit is not readiness, and a failed producer can retain valid partial results requiring a separate scoped audit. Producers report acquisition facts; independent acceptance binds full sample/group membership, native metadata, both index hashes and a content-addressed proof. Equal counts or a few displayed examples cannot establish complete membership; benchmark eligibility remains separate.

Let healthy jobs run without repeated agent polling. Use compact on-disk status and failure/completion hooks when supported, retain dated observations, and follow the download skill's proportional monitoring cadence. Save continuation commands and limits in the project. Use [machine operations](sampling/machine.md) for conditional local commands and [empirical evidence](sampling/evidence.md) only as historical tuning evidence.
